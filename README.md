# darrylpatterson.com

The personal site of Darryl Patterson, rebuilt in 2026 on Next.js 16 and
Tailwind CSS 4. Four pages, static, with one living hero that changes with the
season and the weather in the Algoma region.

```
pnpm install
pnpm dev
pnpm verify
pnpm test:e2e
```

See CLAUDE.md for the conventions and AGENTS.md for the map. The code is MIT;
the words and photos are © Darryl Patterson.
